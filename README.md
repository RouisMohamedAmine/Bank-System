🏦 Bank Management System

A console-based Bank Management System developed in C++ using Object-Oriented Programming (OOP) principles. This project simulates banking operations, including client management, transactions, user management, and currency exchange.

✨ Features

👥 Client Management

- Add new clients.
- Update, delete, search, and list clients.
- View client information.

💳 Banking Transactions

- Deposit money.
- Withdraw money.
- Transfer money between clients.
- View total balances.
- Keep a transfer log.

🔐 User Management

- User login and authentication.
- Add, update, delete, and search users.
- Manage user information.

💱 Currency Exchange

- List available currencies.
- Search for currencies.
- Update currency exchange rates.
- Calculate currency conversions.

📂 File Handling

- Store and retrieve client, user, and currency data using text files.
- Maintain login records and transfer logs.

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Microsoft Visual Studio

🧠 Concepts Practiced

- Classes and Objects
- Encapsulation and Inheritance
- Code Reusability
- Input Validation
- File Handling
- Modular Code Organization

🚀 Getting Started

1. Clone or download this repository.
2. Open "Bank System.sln" in Microsoft Visual Studio.
3. Build the solution.
4. Run the application.

This project was developed as a practical application of Object-Oriented Programming concepts, with the goal of building a modular banking system and improving my C++ programming skills.
